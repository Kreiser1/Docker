# Подтверждения выполнения

Создавайте здесь файлы `K1-01.md`, `K1-02.md` и далее по ID работ. Основа — [шаблон отчёта](../templates/report.md). Сохраняйте только значимые строки вывода и свои объяснения. Файлы пока пусты намеренно: это место ваших результатов, а не готовых ответов.

Для итоговой работы также сохраните экспорт панели Grafana в `K4-02-dashboard.json`. Ссылки на PR, SHA и Actions фиксируются в описании сдачи.
