## Требования к работам и оцениванию

- **Каждая работа оценивается внутри своей КТ.** Выполненные критерии дают частичный балл; полного балла только за статус «сдано» нет.
- До выполнения вы видите максимум, критерии и ожидаемый результат. Общие правила — в [оценивании](docs/GRADING.md).
- Сдаётся работающая конфигурация/код и краткое подтверждение в `evidence/`. Один скриншот без файлов и объяснения недостаточен.
- Нужно уметь объяснить свою работу и выполнить небольшое изменение. Готовый шаблон и помощь разрешены с указанием источника; они не заменяют проверку понимания.
- Работу можно доработать по замечаниям. Повторная попытка повышает балл той же работы, а не добавляет вторую сумму.
- Присутствие, количество разговоров и число коммитов баллов не дают. Содержательные активности уже включены в критерии работ.
- Баллы выставляет преподаватель в отдельном Google-журнале. Ссылка будет предоставлена преподавателем; журнал с персональными результатами в этот репозиторий не входит.
- Сроки по группам и перевод баллов в отметку объявляет преподаватель по расписанию и правилам колледжа. Здесь нет выдуманных дат и проходных порогов.
