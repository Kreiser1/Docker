# Если не получается

| Симптом | Что проверить | Чего не делать |
|---|---|---|
| `docker` не найден / нет Server | Покажите преподавателю вывод `docker version` | Не устанавливать самостоятельно |
| `image ... not found`, pull запрещён | Преподаватель должен подготовить `devops-course:base` и tools | Не подменять случайным образом |
| Порт 8080 занят | `docker compose ps -a`; уточнить, не запущена ли другая учебная копия | Не останавливать все контейнеры ПК |
| `api` unhealthy | `docker compose logs --tail=20 api` | Не удалять том requests |
| Страница есть, заявка не отправляется | Сравнить `/health`, `/api/requests`, статус api и логи web | Не считать HTML доказательством работоспособности API |
| Tools не запускается | Сначала `docker compose up -d`; api должен быть healthy | Не запускать диагностику PID остановленного контейнера |
| В Compose обращение к localhost не работает | Внутри web это сам web; API доступен как `api:8000` | Не копировать порт 8080 вместо внутреннего 8000 |
| После правки app.py ничего не изменилось | Код скопирован при сборке: пересобрать образ и пересоздать сервис | Не ожидать live reload без bind mount |
| Registry push не работает | Сервис registry запущен, адрес `localhost:5000`; показать ошибку преподавателю | Не отключать TLS для внешних сервисов |
| Actions зелёный, тест не запускался | Проверить имя workflow, шаг теста и лог unittest | Не считать любой зелёный workflow сдачей КТ 3 |
| Fork не выполняет Actions | Открыть Actions своей копии, включить запуск; проверить ограничения аккаунта | Не давать чужие токены |
| Grafana показывает No data | Проверить Prometheus Targets и запрос, подождать минимум 2–3 scrape-интервала | Не менять datasource на localhost внутри контейнера |
| Ansible не видит banner.yml | Файл должен называться `ansible/banner.yml`, а не `.example` | Не ставить Ansible на Windows вручную |
| Второй Ansible запуск снова changed | Проверить, не используется ли изменяющееся время или случайное значение | Не скрывать проблему скриншотом первого запуска |

При ошибке сообщайте три вещи: команду, последние значимые строки вывода, что ожидали получить. Это часть инженерной диагностики.
